# 🚗 BMW Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze BMW sales data and explore sales performance across different car models.

The dashboard covers four BMW models: M3, i8, X3, and X6, providing insights into sales trends, pricing, geographic distribution, and customer preferences.

## 🎯 Project Objectives

* Analyze sales performance across different BMW models.
* Track sales trends from 2022 to 2024.
* Explore average prices and sales volume.
* Analyze geographic sales distribution.
* Understand customer preferences based on car color and transmission type.

## 📊 Key Insights & Analysis

* **Model Analysis:** Compare sales performance across BMW models.
* **Sales Trends:** Track yearly sales performance from 2022 to 2024.
* **Pricing Analysis:** Explore average prices across models.
* **Geographic Analysis:** Examine sales distribution across countries.
* **Color Preferences:** Analyze sales by car color.
* **Transmission Analysis:** Compare Automatic and Manual transmission sales.
